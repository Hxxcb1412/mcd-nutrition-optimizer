场景三 · 儿童分段

「我家 7 岁孩子，吃麦当劳要注意什么」

按年龄三段取阈值，额外加一道类别过滤。缺数据时主动报告菜单缺口。

我家 7 岁孩子，吃麦当劳要注意什么？

第三个套餐为什么不给数字？

「可乐麦炫酷」不在官方营养表里。若强行求和会漏掉这一项，热量明显低估——那比不给数字更糟。所以它拒绝输出部分和，并明确告诉你缺了什么。

三个被修掉的真实 bug

都是实测数据暴露的，不是测试假设

BUG 1

无糖可乐差点以「0 大卡 2mg 钠」成为最优解

原判据是「四个字段全为 0」，但无糖可乐的碳水是 1 而非 0，于是被当成真实数据。改为「热量与蛋白质同时为 0」——任何真实餐品都不可能既无热量又无蛋白质。

BUG 2

「清淡午餐」收敛到三样饮品

纯钠优先时最优解是「冰美式 + 可乐 + 纯牛奶」——钠最低但只有 8g 蛋白。根因是低钠食物集中在奶品类，而正餐类钠普遍 500-1000mg。

BUG 3

给 4 岁孩子推荐了汽水加牛奶

关键词表里「纯牛奶」含"牛"、「热浓浓抹茶牛奶」含"蛋"（浓蛋绿），都先命中了"蛋白"类，于是「可乐 + 纯牛奶」通过了「必须含主食或蛋白」的校验。成人场景下这只是荒谬，儿童场景是严重不当。
