这个项目在做什么

你说「想吃得清淡点」，它把口语偏好翻译成数值约束（钠 ≤ 500mg、热量 ≤ 600kcal），再用官方 156条有营养数据的餐品算出最优组合——不估算、不用 0 冒充缺失值、命不中就明确说没有。

为什么强调这些：官方营养表对门店菜单的覆盖率只有 21.1%。用户看到活动推荐下单，很可能算不出它的营养值。我们选择如实告知，而不是给一个编出来的数字。
