# 演示录制脚本

GitHub 上带视频的项目转化率明显更高（冠军 `mcd-event-radar`有 3 分 52 秒
的演示视频，我们没有）。这个脚本你照着跑一遍，剪成 60-90 秒即可。

**不需要露脸，不需要麦克风。** 屏幕录制 + 字幕就够。

---

## 准备

1. 浏览器全屏（F11），窗口宽度调到 1200 左右
2. 关掉所有通知、书签栏
3. 准备好这几个页面（都已在线）：
   - https://hxxcb1412.github.io/mcd-nutrition-optimizer/child-interactive.html
   - https://hxxcb1412.github.io/mcd-nutrition-optimizer/data-gap-report.html

**录制工具**：OBS Studio（免费）、Windows 自带 Win+G、或手机拍屏幕亦可。

---

## 60 秒分镜

### 0-8 秒 · 开场钩子

打开 `child-interactive.html`，滑块停在 **4 岁**。

> 字幕：**给 4 岁孩子点麦当劳，能算出多少钠吗？**

**动作**：拖动滑块从 4 岁到 17 岁，慢慢拖，让观众看到数字在变。

### 8-25 秒 · 展示核心能力

滑块回到 **7 岁**。

> 字幕：**3-17 岁，15 档，每档都是求解器现场算的**

**动作**：缓慢滚动展示方案卡，停在第一条进度条。

> 字幕：**钠 380mg / 上限 1000mg——一眼看出超标多少**

**动作**：指一下三条进度条。

### 25-40 秒 · 反转：算不出的部分

切到 `data-gap-report.html`，滚到「营养表未收录的活动餐品」。

> 字幕：**但它会告诉你哪些算不出来**

**动作**：手指划过龙焰鸡腿堡、马苏里拉拉丝芝士条那几行。

> 字幕：**活动推的新品，官方营养表收录率 0%**

**动作**：指那个 0% 的大数字。

### 40-52 秒 · 数据诚实度

回到交互页，滚到「这份菜单满足不了什么」。

> 字幕：**菜单覆盖率只有 21.1%，128 个餐品27 个能查到**

**动作**：指覆盖率的数字。

### 52-60 秒 · 收尾

> 字幕：**不估算 · 不填 0 · 命不中就说没有**
> 字幕：**点个 Star ⭐**

**动作**：指屏幕下方的 Star 按钮。

## 录制技巧

| 要点 | 说明 |
|---|---|
| **语速** | 比平时慢 20%。观众是静音看的，靠字幕理解 |
| **鼠标** | 放大光标或用圆点标注，指向哪里要看清 |
| **节奏** | 每个关键数字停留 2 秒以上，让观众读完 |
| **不要** | 不要快速连续切页，看不清 |

## 剪辑

- 开头不要 logo 动画，**第 1 秒就要有信息**
- 字幕用大字，居中或下方三分之一处
- 时长 **60-90 秒** 最合适，超过 2 分钟完播率骤降
- 导出 mp4，**控制在 10MB 以内**（GitHub 页面加载更快）

## 上传位置

录好后传到 GitHub Release 或直接放 `docs/`：

```
docs/video/demo.mp4
```

然后在 README 首屏引用：

```markdown
![演示视频](docs/video/demo-poster.jpg)

🎬 [点击观看完整演示（60 秒）](docs/video/demo.mp4)
```

**记得在 README 里放一张视频封面图**（视频第一帧截图），
因为 GitHub 默认不自动播放 video 标签。

## 更省事的替代方案

如果不想录视频，还有两个选择：

**A. 做成 GIF** —— 用 ScreenToGif 录交互页拖滑块的那 8 秒，
嵌入 README 的「拖一下滑块」章节。循环播放，不需要点击。

**B. 只放截图** —— 已经在做了，5 张截图分别放在 README 各章节。

GIF 方案成本最低且效果不错，推荐优先试。
