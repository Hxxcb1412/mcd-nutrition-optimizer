基于麦当劳官方 MCP 实测数据

你孩子的午餐，
钠超标了吗？

输入年龄，从麦当劳 156 条有营养数据的餐品里，找出真正适合该年龄段的组合。不估算，不填 0。

实测对话

家长：我家 7 岁孩子，吃麦当劳要注意什么？
按学龄儿童（7-12 岁）的参考标准：热量 550–750 kcal、钠 ≤ 1000 mg、脂肪 ≤ 25 g。
这是通用人群参考值，不是医疗建议，也不能替代儿科医生的意见。

三档年龄阈值

营养数值来自麦当劳官方接口，年龄阈值来自通用膳食参考值——两者性质不同，必须分开看。

年龄段热量 kcal钠 mg脂肪 g
学龄前（3-6 岁） 350–500 ≤ 800 ≤ 18
学龄儿童（7-12 岁） 550–750 ≤ 1000 ≤ 25
青少年（13-17 岁） 700–950 ≤ 1500 ≤ 32

这份菜单满足不了什么

  • 全表 8% 的餐品钠含量超过 1000mg 上限。这是数据事实——麦当劳的菜单设计本就不是低钠餐。

数据来源

营养数值：麦当劳 MCP list-nutrition-foods 实测抓取， 全量 160 条（158 个唯一名称），其中 4 条因官方未收录而无数据。
年龄阈值：通用人群膳食参考值，非麦当劳官方数据，非医疗建议。
